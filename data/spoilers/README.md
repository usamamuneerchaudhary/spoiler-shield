# ⚠️ This folder contains story spoilers

Every file in here exists to describe spoilers, so reading them will spoil the story.
If you haven't finished the game, close this folder now.

- `generic.json` holds words that are spoilers in any story (endings, deaths, twists). It is safe to read.
- `chapter-NN.json` files (for example `chapter-03.json`) hold spoilers from that chapter. **Not safe to read.**

How to add spoilers: see [CONTRIBUTING.md](../../CONTRIBUTING.md).
